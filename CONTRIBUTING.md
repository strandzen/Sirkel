# Contributing to Sirkel

I hope you enjoy using Sirkel. If you're here, you may want to help by contributing to the project.

## How to contribute

1. Translate Sirkel to your language. Look at po/README.md
2. If you have any ideas on improvements or features to be added, you can submit an issue. All issues are greatly appreciated.
3. Report bugs and crashes, since Sirkel is a Desktop Effect, crashes are critical to catch.
